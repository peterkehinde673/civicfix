# CivicFix — Autonomous Community Resolution Engine

CivicFix is an autonomous AI agent for community problem resolution. It ingests unstructured municipal reports (text & photos), reasons about severity and routing using Gemini, dispatches work orders to simulated municipal departments, tracks progress, and independently verifies visual evidence before closing cases.

## Core Loop
`UNDERSTAND → PLAN → ACT → WAIT → VERIFY → RECOVER/ESCALATE → RESOLVE`
